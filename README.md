# Гараж 17 — сайт автосервиса с онлайн-записью

Адаптивный сайт автосервиса (Минск): каталог услуг, калькулятор стоимости и 4-шаговая онлайн-запись.

## Демо

https://nkorshun.dev/garage-17/

Это демо-проект: заявки никуда не отправляются. После отправки формы показывается экран «Заявка принята» с номером заявки.

## Возможности

- Калькулятор: тип авто, услуги, свои/наши запчасти, мгновенный пересчёт
- Многошаговая запись (авто, услуги, дата и время, контакты) с валидацией на каждом шаге
- Свой календарь на 14 дней: воскресенье выходной, прошедшие дни недоступны
- Черновик формы в localStorage
- Имитация отправки заявки с задержкой и номером заявки, защита от двойной отправки
- Адаптивность от 320 px, управление с клавиатуры (меню, FAQ, слайдер, календарь), видимый фокус, контраст текста не ниже 4.5:1

## Стек

HTML5, CSS3, ванильный JavaScript (ES-модули), Netlify.

## Структура

```
index.html
css/styles.css

.gitignore  netlify.toml  README.md
```

## Локальный запуск

```
npx serve .
```

Сборка не нужна: это статический сайт.

## Деплой

Netlify, публикуется корень проекта (настройки в `netlify.toml`):

```
netlify deploy --prod
```

## Вопросы для собеседования

- Зачем валидация на каждом шаге формы? Пользователь сразу видит ошибку там, где её допустил, а не в конце длинной формы.
- Что такое honeypot? Скрытое поле, которое человек не заполняет, а бот заполняет; такие заявки можно молча отбрасывать.
- Почему localStorage в try/catch? В приватном режиме или при запрете хранилища доступ бросает исключение, а сайт должен работать и так.
